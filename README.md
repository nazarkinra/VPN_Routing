# VPN Routing

VPN со сплит-маршрутизацией: российские сайты и локальная сеть идут напрямую, остальное — через
VLESS/Hysteria2-сервер, сайты МГТУ — через корпоративный OpenVPN. Перенос шлюза с Raspberry Pi
на устройства.

## Скачать для Android

**[VPN_routing.apk](VPN_routing.apk)** — Android 7.0 и новее. Скачайте на телефон, откройте и разрешите
установку из этого источника. Новая версия ставится поверх старой, настройки сохраняются.

Собирается командой `android\publish_apk.ps1` (подписанный выпуск кладётся сюда, в корень).

## Состав репозитория

| Папка | Что внутри |

Подробности, сборка и устройство — в README каждого приложения.
